这是一篇用来验证排版的测试稿喵。如果你在草稿箱里看到代码块和表格都变成了图片，说明转换是通的喵。

## 为什么需要这篇

小黑盒的富文本白名单比较窄，`<pre>` 和 `<table>` 直接发出去会塌成一坨纯文本喵。所以转换器把这两样渲染成图片内嵌喵。

## 一段代码

```python
def render_post(markdown: str) -> str:
    html = converter.convert_markdown(markdown)
    return html
```
