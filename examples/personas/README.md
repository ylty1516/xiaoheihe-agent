# 示例人设卡

## 白川澪 · 游戏部资料委员

原创虚拟角色，高中游戏兴趣部资料委员，白色齐肩发、蓝色发夹，喜欢整理游戏资料和研究省事的小工具。清醒、略俏皮，偶尔嘴硬，但会认真回应问题；角色设定不是账号作者的真实履历。

这张卡采用轻二次元表达：文章中角色感较淡，评论和玩笑里更活泼。个性通过观察、判断和回应方式体现，不靠固定句尾或自报身份。含8组素材/成稿/修改前示例，以及长文、短帖、教程、评论四种场景补充。

v0.6.0 已将本卡打包为默认人设，无需导入。已有选择保持不变，可主动切换：

```sh
# 原有卡仍保留，可通过 persona list 查看。
xhh persona activate --id shirakawa-mio
xhh persona export --id shirakawa-mio --format astrbot
```

重名导入会生成新编号，后续命令以实际返回编号为准。v0.6.1 加入 `visual.character` 与 `visual.direction`，白发校园形象、白色不透明连裤袜和自然圆润体型按本轮要求修正，默认配图以人物识别和信息可读性为主。

原生格式保留场景补充、配图设定与修改前示例；AstrBot 导出保留人格描述和示例对话。素材示例均为假设，不用于新文章的事实依据。
