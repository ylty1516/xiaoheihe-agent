# 文风：从热帖语料反推的写作规则

这份文档不是审美意见，是从真实热帖里统计出来的。每次写完复盘，如果有新发现，补到这里。

## 语料与方法

- 样本：首页热门 + 影之刃零相关高赞帖，13 篇，32814 字
- 抓取：`fetch_feed_posts` + `fetch_post_detail`，正文去掉 HTML 后落盘
- 统计：标点频次、句长分布（按 `。！？` 与换行切分）、高频词

复现命令见文末。

## 硬规则（语料里几乎不出现，写了就是破绽）

| 项 | 语料实测 | 结论 |
|---|---|---|
| `「」`直角引号 | 32814 字里 **0 次** | 不要用 |
| `——` 破折号 | 4 次（每千字 0.12） | 不要用 |
| `；` 分号 | 5 次（每千字 0.15） | 一篇最多一个 |
| 用户禁词 | — | 不过 / 但是 / 然而 / 其实 / 虽然 / 说实话 / 综上 / 值得注意 / 此外 / 因此 / 总而言之，`check_post.py` 会拦 |

注意：`打不过` 这类词也会命中「不过」，改写时换成「赢不了」「打不动」。

## 句长

- 语料中位数 **59 字**，平均 110 字（长段落靠逗号推进）
- 目标区间 **40–60**
- 短句连击（平均 20 出头）读起来像机器播报，是典型的 AI 痕迹

## 高频口语词（可以放心用）

然后 · 因为 · 就是 · 根本 · 觉得 · 结果 · 直接 · 还有 · 但是（注意禁词）

## 报告体黑名单

这些结构一出现，整篇就变成项目总结了：

- 先说结论
- 三个原因叠在一起：一、二、三
- 关于这份整理的可靠性
- 一份给强迫症的清单
- 综上 / 由此可见

替代做法：把结论藏进第一段的具体事里；要列举就直接分段，不加「一是二是三是」。

## 第一人称的边界

**只能写真实发生的事**：翻攻略、核对来源、看任务名时的误解、查资料。

**不能写**：打了多少小时、死了几次、手感如何。没玩过就是没玩过，编经历比写错数值更伤。

需要「玩家视角」时，引真实玩家的原话，并注明是引用。

## 改写对照

原（报告体）：

> 第一张地图就有个陷阱。一处藏起来的龙柱，里面能打到叶师傅，现在硬上基本是送。这地方不难找，难在大部分人根本不知道有这么个入口，所以下面按走位的顺序拆一遍。

改（人说话）：

> 悲泣溪谷有个地方，我翻攻略的时候才注意到。路边宝箱里那把锈蚀的龙形钥匙，是开龙柱用的，很多人开完箱就走，压根没往这上面想。

差别：不预告结构、不总结、句子跟着思路走、第一人称只落在真实动作上。

## 配图

- 用攻略站或社区的真实实机截图，别用自己画的示意图
- 转载水印保留，等于自带出处
- 每篇 3 张，位置跟着内容走，不要堆在结尾

## 交付前检查

```bash
py scripts/check_post.py .data/post.md      # 字数、禁词、表情、配图
```

外加自查：

- [ ] `「」` 与 `——` 计数为 0
- [ ] 平均句长 ≥ 35
- [ ] 没有「先说结论 / 综上 / 清单」这类结构词
- [ ] 第一人称的每一句都能对上真实行为
