# DSH Go 手机原生适配

适配 [ccch1mneyyy/dsh-Go](https://github.com/ccch1mneyyy/dsh-Go)，参照其原生插件规范，本次 SDK 验证提交 `e68525951f98d250768ee5b1c7b0eb4a83ef6140`。

手机输入框上方有「自动成稿」「保存素材」两个胶囊。写一句要求后点自动成稿；留空默认找 GitHub 开源项目话题。也可把输入框随记归档，稍后点素材直接成稿。创作台可从「全部功能」或对话插件面板打开，自动刷新任务，支持预览、复制、暂停、继续、取消及切换人设，或交给聊天助手继续配图和处理。

按钮默认只生成本地稿，不把点按误当公开发布授权。自动发布仍按已有账号约定由助手执行 `xhh autopilot ... --publish --yes`，任务检查和结果不明禁止重发的逻辑共用 Python 后端。

适配器版本 **0.5.0**，配合 Python 后端 **0.8.0 或更新版本**。人设列表只显示名称与修订，不下发私人描述；切换影响后续任务。继续任务不会为仍在运行的任务重复启动，结果待核对的任务仍不可重发。

### 手机面板

- 「创作设置」可选按材料决定篇幅、短帖或长文；配图可选按需或不配图；题材可选游戏、硬件、软件、AI 或按本次要求。设置按当前对话隔离，影响新任务和素材成稿，重启引擎后恢复默认；既有任务不变。
- 点「创作设置 → 发布分区」，可快速添加 GitHub、AI、PC游戏，点击已选项移除；最多五个，至少一个。默认跟随同一主机后端的设置（初始 GitHub / AI）。选题和分区相互独立，不额外追加PC游戏。
- 搜索其他分区时仅使用一个原生搜索框，结果显示真实名称与ID，点击添加。支持视图v2的客户端显示搜索表单；旧客户端保留快捷选择、移除、跟随默认与保存默认。搜索需要后端已登录，失败会提示。
- 修改选择只影响当前对话后续新建任务；「跟随默认」恢复继承，「设为默认」持久保存到同一主机后端，与网页控制台共用。手机本机与远程电脑分别是不同主机，不跨主机同步。已创建任务冻结分区，详情可查看。
- 任务每组 8 项，可翻组查看后端最近 20 项；选中任务独立读取，不会因为新任务挤出列表就切走。任务标题旁显示当前状态和检查提醒。
- 正文每页最多 1800 个 UTF-16 单元，避免原生控件的单段上限截断；可翻页查看和逐页复制。八千字符以内的正文可以完整复制，超长稿可逐页复制或交给助手导出。
- 暂停、继续、取消按后端状态显示；等待配图时说明接续方式，结果待核对时不提供重复提交入口。
- 素材、人设和正文读取分别降级，单项失败不再把整个面板标为断线。后端断线会清空可复制旧稿，保持任务选择并每四秒自动重连。
- 素材成稿与输入框成稿共用启动中的防重复点按保护；超时后仍需先核对任务，适配器不自动重试提交。

## 在手机本机引擎安装

在 DSH Go 的 Linux 环境内执行，Python 至少 3.11、Node 至少 22.19；需要 Git、pip、venv。若 Ubuntu 缺少 venv，先安装发行版的 `python3-venv` 软件包。

```sh
git clone --branch master https://github.com/ylty1516/xiaoheihe-agent.git
cd xiaoheihe-agent
python3 -m venv .venv
.venv/bin/python -m pip install -e .
dsh plugin --profile web add "$PWD/integrations/dsh-go"
.venv/bin/xhh auto --no-open --root "$PWD"
```

保留最后的服务进程；也可使用当前主机已有的进程管理器运行。模型沿用项目本机配置，或在启动服务前设置 `XHH_LLM_BASE_URL`、`XHH_LLM_MODEL`、`XHH_LLM_API_KEY`。DSH 聊天模型的密钥不会被插件自动读取。发起社区查询前先 `xhh login`；已有资料成稿可以不登录。账号与密钥留在当前主机，不写进插件清单。

已有安装：`git pull --ff-only` 后重新执行 `.venv/bin/python -m pip install -e .`，再重启小黑盒服务和 DSH 引擎。

项目放在哪里都可以，安装后的插件链接不能删除。更新 `lib/` 代码后按 DSH Go 说明重启引擎；Python 代码更新后重启小黑盒服务。

## 远程连接电脑

插件代码和小黑盒后端必须装在同一个 DSH 主机上，连接的是主机的 `127.0.0.1:8765`，不是手机的回环地址。可通过 SSH 使用电脑主机；原生胶囊和面板还要求该主机具备 DSH Go 原生桥接。只有普通 DSH/DSHarness Remote 而没有桥接时，不能保证这些原生入口显示，可直接在聊天中调用现有 CLI。

已有后端监听其他端口时，在 DSH 引擎环境设置 `XHH_WEBUI_URL=http://127.0.0.1:端口`。仅允许回环地址，不要把带账号权限的 WebUI 绑定到 `0.0.0.0` 或映射到公网。手机本机引擎与电脑是两套会话、文件与模型配置，不自动复制凭据。

## 图片和实际验证范围

等待生图时点「交给助手」，助手按当前宿主提供的工具与已有授权接续。DSH Go 本身不等于拥有 Codex 的内置生图能力，也不保证提供 `image2.5`；没有生图工具时保留正文与待配图任务。

创作台、设置、人设采用v1原生 JSON组件，分区搜索按客户端能力提供v2表单；均不依赖 WebView 或桌面宽度。已用上游 SDK 的 `--load` 检查原生清单、处理器和全部面板位置，并用 Node 测试验证 HTTP 契约、长文分页、旧任务选择、选中任务竞态、重复点按、断网与订阅释放。分区测试额外覆盖真实SDK桥接分发、v1/v2视图预算、默认值继承、会话隔离、保存、搜索竞态及两种成稿入口；没有在 Android 真机安装 APK 验证。HTTP 测试使用本机测试服务和替身，不调用真实账号或模型。

```sh
node --test integrations/dsh-go/test/*.test.js
# 在 dsh-Go 仓库检出上述基准提交后：
node /path/to/dsh-Go/sdk/plugin-kit/bin/check.mjs integrations/dsh-go --load
# 同时用 SDK 校验填入真实结构数据后的面板（不设置时该项测试跳过）：
DSH_GO_SDK=/path/to/dsh-Go/sdk/plugin-kit node --test integrations/dsh-go/test/*.test.js
```

创作台的「每日任务」复用创作设置面板，可查看进度、执行任务和切换自动执行。首次App短信授权需在运行后端的主机控制台完成；手机本机引擎可在本机浏览器打开复制的地址，远程电脑则需在该电脑浏览器打开。分享流程不会发送微信/QQ消息；未适配任务保留未完成。详见[每日任务说明](../../docs/daily-tasks.md)。
