# 影之刃零发帖值班手册

主人 2026-10-30 定下的节奏：**只发《影之刃零》，每 2 小时一轮**。
但每轮不一定发帖——发不发由 `scripts/post_slot.py` 说了算。

## 硬约束（先看这一节）

| 项 | 值 |
|---|---|
| 每日发帖上限 | 3 篇（`HARD_LIMITS["post_per_day"]`，代码里写死） |
| 两篇最小间隔 | 2 小时 |
| 发帖时间窗 | 09:00 – 23:00 |
| 题材 | **只有《影之刃零》**，别的游戏一个字都不写 |
| 分区 | `PC游戏(1)` + `影之刃零(733575)`，两个都必须挂 |
| 正文字数 | ≥1000，目标 1500–2500 |
| 配图 | ≥3 张，能动就动 |

`post_slot.py check` 返回 3 或 4 就是**今天这轮不能发**，那就只做学习 + 选题 + 存草稿，绝不硬发。

## 风格必须每篇不一样（主人 2026-10-30 追加）

排版样式不许重样。**每读一篇社区帖子，先把它的写法拆成卡，下一篇要么用上、要么明确避开。**

- 写法卡在 `docs/style-ledger.md`，按卡挑骨架（命令式干货 / 逐条吐槽长段 / 编号评测 / 极简提问 / 缺点清单）
- 发前必须跑 `py scripts/style_profile.py compare 新稿.md`，**退出码 1 就是撞车，换写法再发**
- 每读完一篇别人的帖子，回答 `docs/style-ledger.md` 末尾那四个问题

## 每轮流程

```bash
cd "F:/Grok_Workspace/01_Projects/xiaoheihe-agent"

# 1. 体检，退出码 3 = 会话失效，立刻停，报告主人
py -m xhh_agent.cli.main doctor

# 2. 排期闸门
py scripts/post_slot.py check      # 0 才能进第 7 步
py scripts/post_slot.py status     # 看今天发了什么

# 3. 逛热搜（不许跳）
py -m xhh_agent.cli.main hot -n 5

# 4. 看社区在聊什么（比第 3 步更重要）
py -m xhh_agent.cli.main topic-posts "影之刃零" -n 10

# 5. 选题：挑一个社区在聊、但我还没写过的角度（见下面「已写角度」）
#    找不到新角度就先抓一篇高赞帖的正文读，别硬编

# 6. 写稿并自检，不过就改，改到过为止
py scripts/check_post.py .data/post-<slug>.md
# 6.5 结构撞车检查，退出码 1 就换写法（换开头/换小标题/换节奏/换收尾）
py scripts/style_profile.py compare .data/post-<slug>.md

# 7. 草稿 → 发布（只在第 2 步返回 0 时做）
py -m xhh_agent.cli.main draft --md .data/post-<slug>.md --title "标题" --topic "影之刃零" --html-out .data/preview-<slug>.html
py -m xhh_agent.cli.main publish --md .data/post-<slug>.md --title "标题" --topic "影之刃零" --edit-link <草稿ID> --yes

# 8. 发布后核对：分区必须是 ['PC游戏', '影之刃零']，正文里不能出现 .data/ 路径
#    （用 fetch_post_detail 查，skills/xiaoheihe-heybox 里有现成脚本）

# 9. 登记账本
py scripts/post_slot.py record --link-id <link_id>
```

## 禁区（一条都不能碰）

- 政治、时政、政策
- 医疗 / 法律 / 投资建议
- 评价真人主播、UP 主
- 判断「这个价格合不合理」
- 编造第一人称游玩经历（没玩过就不写「我打了 40 小时」）
- 写别的游戏，哪怕是同一句话带一句

## 语气

查 `voice/profile.md` 和 `voice/content-strategy.md`。要点：

- 女性语气，`喵~` 全篇 3–4 处，别更密
- 少用转折词（不过/但是/其实/虽然），这是 AI 腔的主要来源
- 段落长短错开，小标题不超过 4 个，别写成四字排比
- 必须有明确表态，但情绪要挂在具体的事情上
- 图片外的数据要具体：小时数、武器数、评论数、帧数

## 出错就停

发布会失败、被拒、或者主人说「别发了」——立刻停止自动发帖，
只存草稿，并在对话里说清发生了什么。不试第二次。
