## 更新截图

- 用不含账号凭据的示例工作区，或在截图前确认没有手机号、验证码、Cookie、API key 和私人消息。
- 等待数据及图片实际加载后再截图，使用本机浏览器的正常渲染结果。
- 保留原始尺寸，不用生成图冒充软件截图。浏览器窄屏图标明为 WebUI；只有真实客户端截图才能标为 DSH Go / Android 实机。
- 更换首页示范时同时更新案例链接、版本与图片索引；不要仅替换图片而保留旧结论。
