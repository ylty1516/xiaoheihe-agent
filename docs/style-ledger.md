# 写法档案（风格不许重样）

主人 2026-10-30 加的要求：**帖子风格要多样，排版不能每篇一个样；每读一篇别人的帖子，
都要把它的写法拆出来，下一篇用上（或明确避开）。**

规矩只有一条：**下一篇必须和最近两篇在至少 3 项结构特征上不同**，这项用脚本判：

```bash
py scripts/style_profile.py compare .data/post-新稿.md
```

撞车（退出码 1）就换写法，不换内容——换开头、换小标题密度、换段长、换收尾。

---

## 从社区拆出来的写法卡

不是「参考一下」，是能直接照抄的骨架。每篇帖子发出去之前，至少从里面挑**一种**当骨架。

### 卡 1 命令式干货（社区样本：超分输出调到 100%，486 字，1119 评）

- 标题是一句命令：「所有人 立刻 超分辨率输出调整至 100%」
- 没有任何小标题，正文就是三段操作，一段一个设置项
- 每段都是「在哪 → 调什么 → 调到多少」，不给原理
- 结尾追加一句「对仍然觉得 X 不足的朋友，可以试试 Y」
- **适合**：一条能立刻验证的技巧。**不适合**：需要论证的观点

### 卡 2 逐条吐槽长段（社区样本：玩了一会，体验跟白天的帖子都能对上，2755 字，1172 评）

- 纯文本，一个 `<h2>` 都没有，段与段之间靠空行隔开
- 每段只聊一件事，但段长从两句到八句乱跳
- 括号里塞私货：「（话说特效给的是不是太慷慨了）」
- 结尾不总结，直接「不说了，接着玩了，过几天出长评」
- **适合**：体验流动、边玩边想的题材

### 卡 3 编号评测（社区样本：玩了 40 小时，17237 字，1188 评）

- 小标题写成 `01 刀光剑影下的杀气系统`、`02 …`，编号 + 短名词
- 每节先给机制定义，再给一个具体场景，最后给一句评价
- 大量动图，每 300 字一张
- **适合**：把一个机制讲透。**风险**：太工整，容易写成说明书

### 卡 4 极简提问（社区样本：处决按钮亮了为什么不能处决啊，413 字，1556 评）

- 一句话标题，一句正文，一张截图
- 不解释、不铺垫、不提问号以外的任何东西
- 评论区自己长成了一篇长文
- **不是每篇都能这么干**，但每次发长帖之后可以插一条这样的短帖换气

### 卡 5 缺点清单（社区样本：玩了半个小时，抽根烟说下感受，547 评）

- 开头直接给分数：「序章我只能给 7 分」
- 中间缺点罗列，一句一条，不解释
- 收尾给一个反向判断：「能感觉出底子非常不错」
- **适合**：首发期口碑分歧

| 10-30 | 195437564 | 事实判断 | 4 个短语 | 中 | 有 | 问句 | 中 |

两篇撞了 5 项，脚本已经判过一次「撞车」。所以下一篇必须换掉其中至少三项。

**下一篇的默认方案**（不冲突就照这个走）：

- 开头换成**问句或第一人称**（避开「事实判断」）
- 小标题换成**编号式**（`01 / 02`）或者**干脆不要小标题**
- 首屏不放图，第一张图压到第三段之后
- 收尾改成陈述句，或者学卡 2 那样「不说了」直接停
- 篇幅拉到 1900 字以上，跟前面两篇错开档位

## 每读完一篇帖子要回答的四个问题

写进 `.data/` 的临时笔记就行，不用长篇：

1. 它第一句干了什么？（说事实 / 下判断 / 提问 / 抒情）
2. 它靠什么分段？（小标题 / 空行 / 图 / 编号）
3. 它的信息密度在哪一段最高？（机制 / 数据 / 吐槽）
4. 它结尾怎么收的？

四个问题答完，就能挑一张卡来用。答不出来说明这篇只是扫过，没读进去。
