## 拆解时回答

1. 它解决读者的什么问题？
2. 论证顺序是什么，哪些材料支撑哪一步？
3. 哪种证据最有用，哪些只是情绪或装饰？
4. 结构适用于什么情况，何时不应模仿？

保存完整 writing.json 后运行 editorial.py learn，下一次用 library 或面板提纲检索。
不要直接复述他人的结论，也不要模仿虚构体验。
